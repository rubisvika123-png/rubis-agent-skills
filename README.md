# Навыки для тех-спец агентов

Готовые скиллы, которые можно поставить своему агенту так же, как в Уроке 3 —
`git clone` этого репозитория, скопировать нужную папку в `~/.claude/skills/`.

```
git clone https://github.com/rubisvika123-png/rubis-agent-skills.git
cp -r rubis-agent-skills/<название-навыка> ~/.claude/skills/
```

Перезапусти агента (`./start.sh`) — навык подхватится.

## Доступные навыки

- **[reels-montage](reels-montage/)** — монтирует вертикальные Reels из сырых клипов:
  умная нарезка по словам (без потери начала/конца слов, вырезает паузы и дубли),
  ускорение 1.2x, субтитры, текстовый хук первые секунды, музыка. Инструкция и что
  можно менять под свой стиль — в `reels-montage/SKILL.md`.

- **[youtube-shorts-autoposter](youtube-shorts-autoposter/)** — автопостинг YouTube
  Shorts: видео из папки Google Drive → расшифровка → заголовок/описание от LLM →
  публикация на канал. Владельцу нужен свой Google Cloud проект и Groq API ключ —
  подробности в `youtube-shorts-autoposter/SKILL.md`.

- **[razbor-socsetey](razbor-socsetey/)** — разбор соцсетей эксперта или клиента
  (Телеграм, Инстаграм, YouTube, ВКонтакте, TikTok, Threads, сайт) и расписанная под
  него команда ИИ-агентов и воронка продаж. Авторская разработка Виктории Рубис для
  продающих созвонов — подробности в уроке «Заработок на ИИ агентах».

- **[team-backup](team-backup/)** — резервная копия всей команды агентов: каждую ночь
  характеры, память, навыки и настройки уходят в закрытое хранилище на GitHub (без
  токенов и ключей), и одно сообщение техспецу восстанавливает команду на новом
  сервере. Подробности в `team-backup/SKILL.md`.

- **[zadai-voprosy](zadai-voprosy/)** — агент расспрашивает тебя вопросами, пока
  план или идея не станут понятны до конца, и к каждому вопросу сразу даёт свой
  совет. Работа начинается только после твоего «всё верно». Напиши агенту
  «задай мне вопросы» и опиши задачу.

## Моды
